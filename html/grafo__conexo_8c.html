Detailed Description

Graph connectivity module (DFS with UART row streaming).

Authors
Levi Oliveira, Luís Fernando
Date
12/11/2025
Version
1.1

Module Purpose

This module implements a memory-efficient iterative Depth-First Search (DFS) to verify whether an undirected graph is connected. The graph is represented as an adjacency matrix but only one row is ever stored in RAM at a time.

The STM32F030 has only 8 KB of RAM; therefore the full 89×89 matrix cannot be stored. This module requests each adjacency row on-demand from UART.

Internal Data Structures

The following global buffers are intentionally allocated here, since they belong to the graph algorithm rather than to the main application:

  • char linha[90] Stores one adjacency row (89 bytes + '\0' terminator).
  • uint8_t visitado[89] Marks whether each vertex has been visited during DFS.
  • uint8_t pilha[89] Stack used for the iterative DFS.

Total RAM usage of the module: **~268 bytes**.

Algorithm Description

  1. Start DFS at vertex 0.
  2. While the stack is not empty:
    • Pop current vertex.
    • Request its adjacency row via UART.
    • For every neighbor marked '1': push it if not visited.
  3. After DFS, check whether all vertices were visited.

Returns: 1 → graph is connected 0 → graph is not connected -1 → communication error (timeout or invalid byte)

NOTE

This module does not deal with hardware initialization or application-level flow; those responsibilities are handled in main.c.

int verificarConectividade ( UART_HandleTypeDef * huart,
int num_vertices )

Verifies if the graph is connected using iterative DFS with UART streaming.

Runs a DFS-based connectivity test using streamed rows via UART.

The algorithm starts at vertex 0 and explores the graph by requesting adjacency rows on demand via UART. Each row is processed to find unvisited neighbors.

Parameters
huartPointer to UART handle (USART2)
num_verticesNumber of vertices in the graph (89)
Returns
  • 1 if graph is connected
  • 0 if not connected
  • -1 on communication error (timeout or invalid bit)
Note
Global variables affected: linha[], visitado[], pilha[]
Conforms to UM1785 (p. 568): HAL_UART_Receive() with timeout
