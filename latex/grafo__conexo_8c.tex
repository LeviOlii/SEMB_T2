\hypertarget{grafo__conexo_8c_PURPOSE}{}\doxysubsection{\texorpdfstring{Module Purpose}{Module Purpose}}\label{grafo__conexo_8c_PURPOSE}
This module implements a memory-\/efficient iterative Depth-\/\+First Search (DFS) to verify whether an undirected graph is connected. The graph is represented as an adjacency matrix but {\bfseries{only one row is ever stored in RAM}} at a time.

The STM32\+F030 has only 8 KB of RAM; therefore the full 89×89 matrix cannot be stored. This module requests each adjacency row on-\/demand from UART.\hypertarget{grafo__conexo_8c_DATA_STRUCTURES}{}\doxysubsection{\texorpdfstring{Internal Data Structures}{Internal Data Structures}}\label{grafo__conexo_8c_DATA_STRUCTURES}
The following global buffers are intentionally allocated here, since they belong to the graph algorithm rather than to the main application\+:


\begin{DoxyItemize}
\item char linha\mbox{[}90\mbox{]} Stores one adjacency row (89 bytes + \textquotesingle{}\textbackslash{}0\textquotesingle{} terminator).
\item uint8\+\_\+t visitado\mbox{[}89\mbox{]} Marks whether each vertex has been visited during DFS.
\item uint8\+\_\+t pilha\mbox{[}89\mbox{]} Stack used for the iterative DFS.
\end{DoxyItemize}

Total RAM usage of the module\+: \texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}\texorpdfstring{$\sim$}{\string~}268 bytes\texorpdfstring{$\ast$}{*}\texorpdfstring{$\ast$}{*}.\hypertarget{grafo__conexo_8c_ALGORITHM}{}\doxysubsection{\texorpdfstring{Algorithm Description}{Algorithm Description}}\label{grafo__conexo_8c_ALGORITHM}

\begin{DoxyEnumerate}
\item Start DFS at vertex 0.
\item While the stack is not empty\+:
\begin{DoxyItemize}
\item Pop current vertex.
\item Request its adjacency row via UART.
\item For every neighbor marked \textquotesingle{}1\textquotesingle{}\+: push it if not visited.
\end{DoxyItemize}
\item After DFS, check whether all vertices were visited.
\end{DoxyEnumerate}

Returns\+: 1 → graph is connected 0 → graph is not connected -\/1 → communication error (timeout or invalid byte)\hypertarget{grafo__conexo_8c_NOTE}{}\doxysubsection{\texorpdfstring{NOTE}{NOTE}}\label{grafo__conexo_8c_NOTE}
This module does not deal with hardware initialization or application-\/level flow; those responsibilities are handled in \doxylink{main_8c}{main.\+c}.

Verifies if the graph is connected using iterative DFS with UART streaming. 

Runs a DFS-\/based connectivity test using streamed rows via UART.

The algorithm starts at vertex 0 and explores the graph by requesting adjacency rows on demand via UART. Each row is processed to find unvisited neighbors.
