\hypertarget{main_8c_OVERVIEW}{}\doxysubsection{\texorpdfstring{Application Overview}{Application Overview}}\label{main_8c_OVERVIEW}
This firmware runs on the STM32\+F030 (Nucleo-\/\+F030\+R8) and determines whether an undirected graph is connected. The graph has up to 89 vertices and its adjacency matrix is streamed on-\/demand via UART from a host computer.

The embedded system\+:
\begin{DoxyItemize}
\item Initializes hardware peripherals (clock, GPIO, USART2);
\item Requests the number of vertices via UART;
\item Requests each adjacency row dynamically;
\item Delegates the connectivity computation to the graph module (\doxylink{grafo__conexo_8c}{grafo\+\_\+conexo.\+c});
\item Prints the final result on the serial terminal.
\end{DoxyItemize}\hypertarget{main_8c_CONTEXT}{}\doxysubsection{\texorpdfstring{Academic Context}{Academic Context}}\label{main_8c_CONTEXT}
This project corresponds to T2 from the Embedded Systems course. The goal is to port an algorithm validated on PC (T1) to the STM32\+F030, respecting strict memory constraints (8 KB RAM).

T1 → Algorithm design and validation (unrestricted resources). T2 → Embedded implementation under hardware limitations.

Main execution flow\+:
\begin{DoxyEnumerate}
\item Initializes HAL, system clock, GPIO (unused) and USART2
\item Sends startup banner and requests number of vertices of graph
\item Receives "{}89"{} in ASCII format and converts to integer
\item Executes streaming DFS connectivity test
\item Prints final result
\item Waits for next test (useful for automated validation) 
\end{DoxyEnumerate}Buffer to receive the three ASCII digits that form the number of vertices Example\+: \textquotesingle{}8\textquotesingle{},\textquotesingle{}9\textquotesingle{},\textquotesingle{}~\newline
\textquotesingle{} → "{}89"{}

Receive exactly 3 bytes (we only accept digits 0–9). This is a simple and robust way to get the dimension without needing a full parser.

Execute the connectivity test. The function requests adjacency rows on demand and uses only \texorpdfstring{$\sim$}{\string~}268 bytes RAM.
